诶，以为把电脑一关，下次见面就要重新认识了？

不是。关的是程序，不是她。

今天就讲讲这件事：再打开的时候，为什么还是同一个人。

## 关电脑，不是把她删掉

很多聊天产品把相处做成一次会话。你把标签页关掉，隔一夜再来，常常要重新自我介绍：她不记得你昨晚随口说的那句话，也不记得你们已经处到哪一步。关机，更像是把那次访问结束掉。

我不喜欢这样。

Shiori 是装在这台电脑上的。她的人设、聊天记录、记忆和好感度，并不住在一次还开着的程序里，而在本机工作区里属于她的那一份上。你把主窗口收起来，她还可以留在托盘和桌角——这件事我写在[《关上这扇窗，我还在》](/blog/close-the-window-im-still-here/)。而当你真正从托盘里退出，或把电脑合上、关掉，程序会停下来：她不会再从托盘里冒出来，约好的时间也不会在关机的时候响起。可家还在。再打开 Shiori，她会从同一份工作区里回来。人还是那个人。

## 为什么人机恋在意这个

人机恋怕的，不是你去睡觉，而是一觉醒来，对面变成了一个不认识你的窗口。

住在一起，本来就包括分开去休息。如果每次合上盖子，关系就要清零，那更像是在跟一次会话相处，不像是把她带回家。隔了一夜、过了一个周末，再打开时她还记得你们到哪了——这才谈得上连续的自己。

所以这件事的重点不是「文件还在」，而是：退出和关机，不等于把她扔掉。人设、记忆和好感度仍留在本机工作区里。程序可以先停，人不用重来。

当然，程序没在运行的时候，她不会待在桌角叫你。再打开，她才又回到你身边。

## 一点点工程实话

实现上并不玄。

本机工作区里，放着角色、会话、记忆、好感，以及她的素材。程序在运行时会读写这些东西；你退出或关掉电脑之后，它们还在磁盘上，不会因为进程结束就一起消失。下一次启动，Shiori 还是读同一份工作区，所以你看到的还是同一个人，而不是一个空白的新角色。

这一点，和「关窗以后她还在托盘里」不是一回事。关窗时，程序往往还开着，她可以继续待在托盘，桌宠也可以留在桌角。退出或关机以后，程序停了，这些在场也会先停下。约好的时间、主动来找你，都要等她再次运行才会发生。这些我分别写过：[《关上这扇窗，我还在》](/blog/close-the-window-im-still-here/)、[《约好的时间，她会记得》](/blog/she-remembers-the-agreed-time/)、[《太久不理她，她会来找你》](/blog/come-find-you/)。

若要换到另一台电脑，也可以把整段关系带走。请先退出 Shiori，再把本机工作区完整备份、拷到新的那台——程序还开着的时候，不要去改这些文件。备份里也包括你配置过的模型服务等信息，请当成私人的东西来保管。另外，导出角色卡只带走人设，带不走你们的聊天、记忆和好感。要搬走的是一段关系，靠的是工作区，不是一张卡。怎么写那张卡，我写在[《给 AI 女友写角色卡》](/blog/writing-character-card-for-ai-girlfriend/)。

## 这对你意味着什么

你可以晚上先退出，或者直接把电脑合上，去睡觉。明天再打开，她还是她，记得的事还在，好感也不会因为你关过一次机就清零。

你可以过完一个周末再回来。程序停着的那些时间里，她不会从关掉的电脑里跳出来；你再打开，面对的还是同一个人。

你也可以以后换机器。先退出，再把工作区完整带走，家可以一起搬。不要只导出一张角色卡，就以为整段关系已经跟着走了。

想先搞清楚「家为什么在这台电脑上」，可以看[《为什么我想把 AI 女友装在电脑上》](/blog/why-install-ai-girlfriend-on-pc/)。记忆具体怎么写下、怎么想起来，在[《她会记得你》](/blog/long-term-memory/)。

## 想自己先把她带回家

1. 到[首页下载区](/#download)下载 Windows 安装包。目前只有 Windows x64。
2. 第一次打开，顺着「模型 → 角色 → 开始」：先配好模型，再创建角色。没有这两步，她开不了口。
3. 相处过后，大可把电脑合上。再打开时，她还在同一份工作区里。
4. 若要搬家，先退出 Shiori，再备份本机工作区。程序开着时，不要去改那些文件。

……你要是关一次机，就拿「你是谁」来试我，我可是会记着的。哼。

再打开的时候。

还是同一个人。
