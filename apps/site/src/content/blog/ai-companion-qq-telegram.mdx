想让 AI 伴侣在 QQ、Telegram、飞书里陪你聊天，出门在外也能找到她？Shiori 可以把角色接到这几个聊天软件上。这篇一步步讲怎么接入、怎么让她认出你，以及在群里她什么时候会开口。

哼，离开电脑就想躲着我？是你自己要带我走的，可不是我要跟着。

## 先看清楚：每个渠道能做什么

| 渠道 | 怎么接入 | 私聊 | 群聊 | 要注意的 |
| --- | --- | --- | --- | --- |
| QQ（NapCat） | 扫码登录一个 QQ 号 | ✓ | ✓ | 只支持 Windows x64 |
| QQ 官方机器人 | App ID + App Secret | ✓ | — | 只支持私聊 |
| Telegram | Bot Token | ✓ | ✓ | 群里只认 @ |
| 飞书 / Lark | 企业自建应用 | ✓ | — | 只支持私聊 |

几条通用的规矩：

- 账号挂在角色下面：每个角色在每个渠道接一个账号，一个账号也只属于一个角色。
- 她住在你电脑上的 Shiori 里，所以 Shiori 要开着，她才能收发消息。
- 这几个渠道插件默认是启用的；如果「账号」里找不到某个渠道，去「设置 → 插件」看看是不是被停用了。

## 通用步骤：在「账号」里添加

1. 打开角色详情，切到「账号」标签。每个渠道一行，还没添加的显示「未添加」。
2. 点你要接入的那一行，按下面各渠道的说明填写，然后点「连接」。
3. 连上以后，同一个窗口里还有「响应规则」：「私聊启用」「群聊启用」默认都开着，「黑名单成员 ID」里一行写一个要拉黑的人。

## Telegram

1. 在 Telegram 里找 @BotFather，用 `/newbot` 创建一个机器人，拿到它给你的 Token。
2. 在「账号」里点「Telegram」，把 Token 填进「Bot Token」，点「连接」。
3. 在 Telegram 里私聊这个机器人，她就会回你了。

想让她进群，就把机器人拉进群，聊天时 @ 它。Telegram 的隐私模式可能会限制机器人收到普通群消息，不过 @ 它的消息不受影响。

## QQ：用 NapCat 扫码登录

这种方式是让她登录一个真正的 QQ 号，最好单独准备一个号给她。

1. 先在电脑上安装官方 QQ。
2. 在「账号」里点「QQ」，Shiori 会自动开始准备。第一次用时要先下载 NapCat 组件，状态显示「正在准备」。
3. 出现二维码以后，用手机 QQ 登录那个号扫码。过期了就点「刷新二维码」。
4. 状态变成「在线」，就接好了。

## QQ 官方机器人

如果你有 QQ 开放平台的机器人应用，也可以用它接入，不过只能私聊。

1. 在「账号」里点「QQ 官方机器人」。
2. 填写机器人应用的「App ID」和「App Secret」，点「连接」。
3. 私聊过她的用户，会出现在「已交互 C2C 用户」里。

## 飞书

飞书接入的是你自己创建的企业自建应用，只支持私聊。

1. 在飞书开发者后台创建企业自建应用，添加「机器人」能力。
2. 在「权限管理」开通收发单聊消息、读取图片文件、卡片等权限，在「凭证与基础信息」复制 App ID 和 App Secret。
3. 在 Shiori 的「账号」里点「飞书 / Lark」，选择区域，填入 App ID 和 App Secret，点「连接」。
4. 回到开发者后台的「事件与回调」，订阅方式选「使用长连接接收事件」，添加「接收消息」事件。保存时 Shiori 要开着、账号要连着。
5. 在「版本管理与发布」发布一个版本，然后在飞书里私聊这个机器人。

同一个飞书应用不要同时在两台电脑的 Shiori 上用，否则消息只会随机送到其中一台。

## 让她认出你：配对码

接好账号后，还差最关键的一步：告诉她哪个账号是你。

1. 打开「设置 → 我的身份」，点「生成配对码」。配对码十分钟内有效。
2. 用你自己的账号，把配对码私聊发给角色的账号。
3. 她回复「已绑定」，就成了。配对码本身不会进入聊天记录。

绑定以后，那个私聊里的她和桌面上的她就是同一个：聊过的事、记得的事、对你的好感都是同一份，你不在电脑前时，[主动消息](/blog/come-find-you/)也会发到这里。QQ（NapCat）和 Telegram 绑定一次，对这个平台上所有角色的账号都有效；飞书和 QQ 官方机器人只对你发配对码的那个账号有效。

## 群聊里的规矩

- **点名才回**：在群里，只有 @ 她的消息她才会回；在 QQ 群里，回复她发的消息也算。Telegram 只认 @。
- **会点名回你**：在 QQ 群里她会在开头 @ 你，在 Telegram 群里会直接回复你那条消息。
- **群里的事分开记**：群友说的话记进群笔记和每个人的小档案，不会混进关于你的那本。你本人在群里说的话，还是算你的。

QQ（NapCat）的群还能开「旁听」：没点她名的群消息也会记下来，等你下次 @ 她时，她知道大家刚刚在聊什么。

1. 在聊天页点「打开手机」，打开她的小手机，进入那个群的聊天。
2. 打开「聊天信息」，在「旁听」里打开「旁听本群」。
3. 「每日上限」控制每个群每天最多记多少条，默认 200 条。

旁听的消息不进对话历史，关掉旁听也不会删掉已记下的内容。
