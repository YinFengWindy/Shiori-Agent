# 桌宠国内 ASR 供应商选型

> 调研日期：2026-07-25
>
> 场景：Windows 桌面端、Electron 桌宠、按住说话，松开后将一段中文短语音转写并自动进入角色 Loop。TTS 另选供应商，不要求 ASR 和 TTS 属于同一家。

## 结论

首版推荐 **腾讯云语音识别**，优先使用“一句话识别”完成松开后的短音频转写；如果后续需要在用户说话过程中显示实时文字，再接入腾讯云实时 WebSocket 识别。

腾讯云适合首版的原因是：短音频接口的边界清楚，实时接口成熟，普通话、粤语和多种方言覆盖明确，国内网络路径和公开计费信息也更容易验证。官方公开信息显示，实时识别每月有 5 小时免费额度，一句话识别每月有 5000 次免费额度；预付费实时识别大模型 2.0 约从 1 元/小时起，一句话识别约从 3 元/千次起，具体仍以地域、版本和控制台阶梯为准。

**火山引擎/豆包语音**应作为低延迟候选。其双向流式接口适合边说边返回字符，文档建议每包发送 100–200ms 音频；流式输入模式在特定条件下给出了 300–400ms 级别的返回延迟。但其价格同时受到模型、按时长/按并发、资源包和套餐阶梯影响，不适合只凭一个公开单价做成本结论。

**阿里云智能语音交互**适合作为企业化备选。其一句话识别明确面向 1 分钟以内短语音，实时语音识别支持不限时长音频流、边说边出文字和智能断句，还支持热词与自学习语言模型。当前能稳定访问的一手产品概览没有给出可直接横向比较的当前价格，因此需要登录账号后再核价。

没有找到 MiniMax 官方文档中明确的 ASR 产品入口。当前应保持 MiniMax 做 TTS，不要因为 TTS 已经选了 MiniMax 就假设它也承担 ASR。

## 官方事实

### 腾讯云

- 一句话识别适合 60 秒以内短音频，单文件不超过 3MB，支持本地数据上传或 URL。
- 实时 WebSocket 识别适合边说边返回文字，适合将来做录音中的实时字幕或更短的首字延迟。
- 官方计费概述列出了按时长、按次数等模式；公开免费额度包括实时识别每月 5 小时、一句话识别每月 5000 次。
- 腾讯云隐私说明要求开发者在具体功能触发时征得用户同意；音频数据加密传输，境内收集的数据存储在中国境内。

### 火山引擎/豆包语音

- 双向流式接口为 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel`，另有流式输入和优化版本。
- 文档建议每包发送 100–200ms 音频；流式输入模式说明平均 5 秒音频可在 300–400ms 内返回结果，实际桌面端延迟仍需要实测。
- 语音识别支持按音频时长计费，也提供并发版、资源包和后付费组合。官方计费示例中，1000 小时资源包价格为 1800 元，超出部分示例按 3.5 元/小时计算；这只是示例阶梯，不应直接当作所有识别模型的统一价格。
- 当前文档中列出了大模型流式识别和豆包流式语音识别模型 2.0 的资源标识，包括 `volc.bigasr.sauc.duration`、`volc.bigasr.sauc.concurrent`、`volc.seedasr.sauc.duration` 和 `volc.seedasr.sauc.concurrent`。

### 阿里云 ISI

- 一句话识别用于语音搜索、指令、短消息和智能助手等 1 分钟以内的短语音场景。
- 实时语音识别支持不限时长音频流，可以边说边返回文字，并提供智能断句。
- 热词和自学习语言模型可以用于优化角色名、专有名词、口语和项目内词汇的识别。
- 公开产品概览把产品定价作为独立学习入口，但当前页面没有稳定呈现可直接引用的统一单价；落地前应按具体接口、地域和账号套餐重新核价。

## 对 Shiori 的建议

首版采用下面的请求链路：

```text
按住说话
  -> 松开并结束录音
  -> 腾讯云一句话识别
  -> { text, duration, provider_request_id }
  -> 现有角色 Loop
```

首版不需要为了追求实时字幕而一开始就使用 WebSocket。桌宠的交互约定是“松开后发送”，一句话识别更简单，失败时也更容易明确提示“请重录”。之后如果首字延迟或长句体验成为问题，再把同一个 `SpeechToText` 接口替换为实时流式实现。

ASR 和 TTS 继续使用独立 provider，不做自动跨供应商 fallback。失败时记录 provider、请求耗时、音频时长和错误码，提示用户重录；不要默认保存原始音频或把完整音频写入会话。

## 实现前压测

不要只按公开价格定案。用同一批 100–200 条中文短句在三家服务上测试：

1. 安静环境、键盘声、桌面扬声器回声和远场麦克风。
2. 普通话、粤语/方言、口语省略、中英混说以及角色名和专有名词。
3. 首个可用结果、最终结果和完整请求的延迟。
4. 字错误率、漏识别率、误触发率、失败重试率和 SDK/API 集成复杂度。
5. 真实账号下的免费额度、阶梯价格、数据保留和删除政策。
