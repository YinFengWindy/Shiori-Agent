# 自动测试聚焦必要行为与高后果失败

状态：维护者于 2026-11-03 要求采用更激进的测试精简标准。

## 决定

是否保留自动测试，取决于它守住的独立失败及后果，不取决于源码是否有可测试的分支，也不设删减比例。

保留真实业务主链路、持久化与兼容、权限与隔离、外部协议、取消与资源清理、失败恢复、可访问性，以及曾发生的关键回归。使用 mock、参数化或读取构建产物本身，不构成删除依据。

普通展示取值、装饰动画、静态文案、图片格式/尺寸预算、单纯布局计算和组件外壳不再逐项维护自动测试。改变这些效果时做定向视觉或交互检查。涉及焦点、交互命中区、减少动态效果偏好、可访问性、内容可达性和内容丢失的约束继续保留。

## 本次边界

- 官网取消图片卫生、叙事动效数学、文案字典和逐篇文章 SEO/排版的细粒度测试；保留构建、草稿发布边界、内容与导航可达性、下载/更新日志安全、语言跳转、可访问性和发布触发逻辑。
- 桌面与插件删除独立的装饰、状态展示、简单布局和页面外壳测试。对导航、消息虚拟化、侧栏和滚动，保留真实 hook/组件交互，删除其下层重复的纯状态测试。动画只保留有界资源和停止/清理检查；错误组件保留可访问性、诊断脱敏和操作检查。
- 删除记忆插件中重复的“未配置隐式处理器不写记忆”测试及其独占 fake，保留同时验证失效处理仍执行的那条测试。
- 宿主删除旧 API 迁移扫描器、CoreRunner 转发测试、私有引用格式化矩阵、用固定模型回答宣称模型会选择 spawn 的测试，以及部分阶段装配和参数回声测试。保留实际被动/主动回合 golden trace、spawn 完成持久化、reasoning loop、kernel 准入与清理、日志脱敏和生命周期边界。
- 插件与 SDK 删除被真实 setup/service/注册器覆盖的私有校验、默认值、构造回读、fake 接线及等价参数样例。保留插件身份/权限、存储兼容、外部请求前校验、配置失败和异步清理。
- 取消默认宿主测试数量必须位于 `950..1058` 的门槛，移除只为该门槛服务的 AST 计数代码。默认 allowlist 去掉已删除的 README/入口文本测试路径及已无测试的 policies 目录；目录检查要求实际存在测试文件，避免本地缓存掩盖干净检出的缺失路径。增量选择逻辑和关键 kernel 契约的选择检查仍保留。测试数量不再作为需要维护的规格。
- CI 作业、插件隔离验收、打包验证和 E2E 入口不变。图片检查 helper 没有生产调用者，随其测试一起移除。

## 接受的代价

普通样式、文案、素材规格和展示计算的回归不再保证由单测发现。这是减少维护负担的明确取舍；保留下来的测试数量不代表全仓库每条测试都已逐项证明不可删除。

本次不改变产品实现、配置、依赖、持久化格式或发布产物。测试选择支持代码的改动限于退休无消费者的数量统计器和移除失效 allowlist 路径。Git 提交可以完整恢复删除的测试与 helper。
