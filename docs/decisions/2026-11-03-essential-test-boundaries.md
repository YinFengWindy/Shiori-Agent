# 自动测试聚焦必要行为与高后果失败

状态：维护者于 2026-11-03 要求采用更激进的测试精简标准。

## 决定

是否保留自动测试，取决于它守住的独立失败及后果，不取决于源码是否有可测试的分支，也不设删减比例。

保留真实业务主链路、持久化与兼容、权限与隔离、外部协议、取消与资源清理、失败恢复、可访问性，以及曾发生的关键回归。使用 mock、参数化或读取构建产物本身，不构成删除依据。

普通展示取值、装饰动画、静态文案、图片格式/尺寸预算、单纯布局计算和组件外壳不再逐项维护自动测试。改变这些效果时做定向视觉或交互检查。涉及焦点、交互命中区、减少动态效果偏好、可访问性、内容可达性和内容丢失的约束继续保留。

## 本次边界

- 官网取消图片卫生、叙事动效数学、文案字典和逐篇文章 SEO/排版的细粒度测试；保留构建、草稿发布边界、内容与导航可达性、下载/更新日志安全、语言跳转、可访问性和发布触发逻辑。
- 桌面与插件删除独立的装饰、状态展示、简单布局和页面外壳测试。保留聊天消息、Markdown 安全、表单保存、真实交互、任务取消、插件挂载/隔离、语音及资源生命周期测试。
- 删除记忆插件中重复的“未配置隐式处理器不写记忆”测试及其独占 fake，保留同时验证失效处理仍执行的那条测试。
- 宿主默认契约集、SDK 对外契约、插件隔离验收、打包验证和 E2E 入口不因本次精简降级，CI 作业不变。图片检查 helper 没有生产调用者，随其测试一起移除。

## 接受的代价

普通样式、文案、素材规格和展示计算的回归不再保证由单测发现。这是减少维护负担的明确取舍；保留下来的测试数量不代表全仓库每条测试都已逐项证明不可删除。

本次不改变产品实现、配置、依赖、持久化格式或发布产物。Git 提交可以完整恢复删除的测试与 helper。
