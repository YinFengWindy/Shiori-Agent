# 2.5D 形象的通用动画与角色调参

维护者确认在 Shiori 提供待机摆动、眨眼、头发物理和口型调参，并将入口放在角色配置中。参数按角色包保存，不改动原 ZIP 或其绑定数据。

## 入口与保存

角色配置新增「2.5D 动画」卡片，设置对话框列出本角色已导入的 2.5D 形象，默认选中当前桌宠形象。未显示的形象也可配置；显示中的相同包实例实时预览。滑块支持键盘操作，修改沿 SDK 的私有自动保存流程写入，失败显示错误并保留草稿供重试，提供恢复当前形象默认值。

参数由 `pet_2d` background 的单一偏好存储拥有，用不可变包的 manifest hash 索引。同一个包导入多个角色时共享参数，不同版本或不同包相互独立。摄像头设备偏好与动画参数经同一写入队列合并，避免互相覆盖。参数仍留在插件私有数据中，角色显式保存不携带这份草稿。

## 通用驱动

待机提供摆动幅度、呼吸幅度和速度；眨眼单独按间隔控制。身体、衣服、袖子和头部围绕包的身体锚点一起轻摆，颈部衔接头部姿态；默认呼吸不再缩小到桌宠尺寸下不足半像素。头发和带物理约束的饰品接受头部／身体位移惯性与轻风驱动，可调摆动强度、硬度和阻尼，继续遵守固定点、方向和径向位移上限。

语音与面捕分别有口型灵敏度。AI 实际播报的 `playback_id` 继续占有嘴部，包括静音；面捕期间头眼由面捕控制，不叠加自动眨眼。系统减少动态效果时停用待机摆动、呼吸、自动眨眼及头发弹性，保留语音和显式面捕输入。此为 Canvas 动画，减少动态效果由 renderer 的媒体查询统一执行。

不增加 SDK 扩展面、动作文件编辑器、骨骼绑定编辑或手臂动作生成。包已声明的几何和物理约束仍是动画边界。
