# GPT-SoVITS TTS

独立 Shiori TTS provider，通过 SDK `shiori.tts.v1` 发布 `tts/synthesize`。
角色声音编辑和后台原生试听都属于本插件，不依赖桌宠。

## 外部服务

协议固定于官方 GPT-SoVITS commit `b274eae5ee2f1b7e33ea755f60c518a8947aac7f` 的
`api_v2.py`，首发仅支持 v2ProPlus。独立服务的推理 YAML 必须显式设置
`custom.version: v2ProPlus`，并选用 `s1v3.ckpt` 与 `v2Pro/s2Gv2ProPlus.pth`。
官方示例默认 v2，不能直接据默认配置假定模型版本正确。
使用独立推理环境的解释器运行 `<外部环境的python> api_v2.py -a 127.0.0.1 -p 9880 -c <你的推理配置>`，
在插件设置保存 loopback HTTP 地址和两个权重路径。相对权重路径由服务工作目录解析。
插件健康检查只能验证 API 可达，不能证明已加载版本或真实音质。

服务必须与 Shiori 在同一台电脑，并能读取插件返回的绝对音频路径。
角色页导入 3–10 秒、非全零、完整 PCM WAV（上限 32 MiB），设置参考转写、
参考语言、文本语言和语速。合成前须保存默认参考，情绪可以分别导入不同参考；未映射情绪使用
该角色明确保存的默认参考。情绪不会作为上游不存在的 `emotion` 参数发送。
在声音面板输入名称并点击“添加情绪”，再为它导入参考音频；没有角色情绪目录、立绘或
桌宠也可以新增多个私有映射。角色情绪只作建议，新增名称和音频不写入宿主角色配置。
未导入音频的名称属于未完成草稿，须完成导入或删除后才能保存。自动朗读只按调用方
提供的 mood 匹配同名映射；编辑器中的名称不会替调用方选择情绪。
试听使用已保存的配置，和公共合成服务走同一入口。

## 所有权与恢复

单实例锁覆盖配置快照、参考文件 pin、两个权重切换及完整 HTTP 响应。
本服务应专用于该插件；其他客户端并发修改同一外部实例不在插件锁控制内。
没有推理读取期限，也不重试或使用系统代理。调用者取消后只丢弃结果，保留任务与
runtime lease 直到真正完成；试听停止会立即停止播放并屏蔽晚到结果。

连接中断/超时无法证明上游 GPU 工作已结束。插件在私有 `inference.json` 留下
完成状态未知记录并拒绝后续推理；该状态跨插件重载/应用重启保留。必须先重建外部
服务实例，再点“我已重启服务”并确认“确认已重启”，才可清除隔离状态。不会自动重试。
已经获得完整错误响应、无效 WAV 或全零静音也会明确报错；官方上游可能用 HTTP 200
静音表示推理失败，本插件的检查不等于修复上游错误报告。

角色配置位于 `plugin-data/gpt_sovits_tts/voices.json`，不可变音频副本位于其
`references/` 子目录。每次导入使用独立文件身份，即使音频内容相同也不会复用旧实例
正在回收的文件；已保存的旧内容哈希文件名仍可读取。替换/删除角色时延迟回收使用中的素材；停用期间删除的角色
在下次加载时清理。未保存导入素材保留到下次加载，完成状态未知时保留所有可能被
服务读取的素材。新配置不进入宿主配置或 roles.json。

## 安装与验证

要求 SDK / Runtime API 4.1，manifest 为 `distribution: external`。
使用通用 builder 构建普通 ZIP，从插件页面安装、信任、启用、更新、停用与卸载。
在仓库根目录构建：

```sh
node scripts/build-plugin.mjs --plugin plugins/gpt_sovits_tts --output artifacts/plugins
```

从“设置 → 插件 → 安装插件 ZIP”选择产物，确认信任并安装，重启后启用。
Python wheel 独立测试命令见[源码仓库 TESTING.md](https://github.com/YinFengWindy/Shiori-Agent/blob/main/plugins/gpt_sovits_tts/TESTING.md)。不安装大型推理依赖到宿主。
当前协议、队列、取消和文件生命周期通过受控 HTTP 替身验证。未下载模型、未声称
真实试听通过；角色音色/情绪效果、4060 Laptop 延迟及显存验收由 #676 完成。

应用级验收另以实际插件 ZIP、Electron 生产入口和 Python bridge 连接本机 HTTP 替身，
音频使用生成的 PCM。它验证安装与真实应用接线，不等同于独立插件单测或真实模型效果。
