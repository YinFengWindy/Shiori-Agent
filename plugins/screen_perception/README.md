# 24h视奸插件

技术 ID：`screen_perception`。提供当前角色的 `observe_screen` 按需主屏截图与只读分析工具，使用角色配置的视觉模型。

截图仅在本次分析内存中使用，不生成点击、输入或其他桌面控制操作。停用插件会撤销工具并取消尚未结束的分析；与 `desktop_pet` 回复气泡和 `observe` 运行遥测互相独立。

本次迁移对应 [#220](https://github.com/YinFengWindy/Shiori-Agent/issues/220)。持续感知与陪伴扩展留给 [#292](https://github.com/YinFengWindy/Shiori-Agent/issues/292)，当前不提供全天候采集或新增存储策略。
