# 好感（affection）

系统插件。提供 `AFFECTION`：角色对用户的好感、关系快照与寂寞值。角色、会话、在场、记忆文档和对话模型由宿主经 `AFFECTION_HOST` 提供。

## 数据

状态文件仍在 `<workspace>/roles/<role_id>/state/`，路径和格式与插件化之前一致：

| 文件 | 内容 |
|---|---|
| `affection.json` | 当前好感、阶段下限；文件存在即已初始化 |
| `affection_history.jsonl` | 每次变化追加一行，全部保留 |
| `relationship_snapshot.json` | 关系快照（自我感受、关系标签） |
| `loneliness_runtime.json` | 寂寞值与等待回复状态 |

长时间未联系的衰减在读取摘要、心跳和用户发消息时按需补算。寂寞心跳由插件的后台任务运行。

## 界面

- 角色详情的「好感度」页（历史与各阶段指引）。
- 聊天状态栏里的好感区块：关系标签、好感条（只显示阶段和位置，不显示数值）和寂寞值。插件经自己的 `chat_status` RPC 取数，收到该角色的 `session.updated`，或插件自己在寂寞心跳（同时结算衰减）、关系快照刷新后发的 `plugin.affection.chat_status.changed` 后重新读取；宿主只挂载这个槽，不读插件数据。

## 插件关闭时

好感记账、关系快照、寂寞值、好感提示和依赖好感的主动策略（场景追问、寂寞主动）都跳过，聊天照常。数据文件保留，重新启用后继续使用。
