# 即时聊天（natural_chat）

系统插件。只提供 `REPLY_POLICY`：被动回合追加的即时聊天提示，以及主动、发呆草稿追加的提示。

## 选用

插件启用，且角色 `runtime_config.natural_chat_enabled` 是布尔 `True`，才选用即时聊天。插件关闭时，角色开关单独为真也不选用，回复是单条，聊天照常。开关在角色 JSON 里，不进 `config.toml`。

## 行为边界

- 分条协议留在核心：`finish_reply` 校验、分条投递、打断与刷新，都不论插件是否启用。
- 插件只决定提示文本；是否选用由核心按上面的条件判断。
- 没有配置项。
